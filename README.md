## Project Overview

**MotionPulse** is a feature-rich, modern Android application developed by **The 5 Watermelons** designed to promote self-improvement, habit consistency, emotional well-being, and community accountability.

For full project summary and technical documentation, please refer to [PROJECT_NOTES.md](file:///C:/Users/AM Nkuna/AndroidStudioProjects/Motionpulse/PROJECT_NOTES.md).

### Highlights:
- **Habit Tracking & Streaks**: Room-persisted offline-first habit management.
- **Mood Logging & Analytics**: Custom line charts (`WeeklyLineChartView`) and mood journaling.
- **Social Community Feed**: Real-time friend activity, flame reactions, nudges, and group challenges.
- **REST API & Sync**: Retrofit integration and background sync with `WorkManager`.
- **Notifications**: Scheduled local habit reminders and Firebase Cloud Messaging.
